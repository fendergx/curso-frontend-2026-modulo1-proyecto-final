# Portafolio

Sitio web del proyecto final del **Módulo 1: Fundamentos de Desarrollo Web** del curso de Desarrollo en JavaScript. Es una landing page estática de cuatro páginas que comparten una única hoja de estilos `style.css`.

## Páginas

- [Inicio](index.html): presentación
- [Acerca de](acerca.html): perfil, habilidades, herramientas y áreas de interés.
- [Proyectos](proyectos.html): tabla de proyectos con etiquetas semánticas y vista adaptada a móvil.
- [Contacto](contacto.html): formulario con validaciones HTML5 y atributos de seguridad.

## Contenido

- HTML semántico (`header`, `nav`, `main`, `aside`, `section`, `footer`) y jerarquía de encabezados.
- Diseño responsive mobile first con Flexbox, Grid y dos puntos de responsive (`640px` y `900px`).
- Todos los estilos en un archivo externo, sin estilos en línea.
- Meta etiqueta de Content Security Policy (CSP) en cada página.
